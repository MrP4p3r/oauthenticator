Variants — token lifetime bar

iat/exp show as static absolute timestamps (fixed length by construction — no counter jitter to guard against). Hover either one for a custom tooltip with the relative time ("2m ago" / "in 58m"). The lifetime bar itself still needs live current-time to compute its fill %, but that no longer touches label width. Below: the same layout applied to a spread of real timestamps.

the rule
iat/exp render as absolute UTC timestamps, ISO-style and zero-padded: YYYY-MM-DD HH:MM:SS UTC — every value is exactly the same character count, so width is naturally fixed. No relative-text ladder, no fixed pixel slots, no tabular-nums workaround needed.
Relative context ("2m ago", "in 58m") moves into a small custom tooltip, shown on hover of the timestamp — it's supplementary, not load-bearing, so it's free to change width.
Fill/dot/label color by % of life elapsed: 0–70% green · 70–90% amber · >90% red (+ glow).
